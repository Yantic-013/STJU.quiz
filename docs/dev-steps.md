## 每次发布前

1. 运行 `node --check app.js` 和 `node --check sw.js`。
2. 本地 HTTP 打开应用，分别导入机械设计与机械原理最终工作簿。
3. 核对题型数量、章节数量、填空题多空输入和选择题选项映射。
4. 完成一轮混合练习与模拟考试，检查结果页、错题和收藏。
5. 检查手机宽度布局与 Service Worker 注册。
6. 复核 Git 差异后再提交并推送。
