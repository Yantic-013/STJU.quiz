# UI 设计约定

## 原则

- 以长时间刷题的清晰度和操作效率为主，不使用装饰性图形干扰内容。
- 选择题、填空题使用不同但克制的标签色；正确、错误、警告保持一致语义。
- 题图保持原始比例，限制最大高度，不裁切、不拉伸。
- 按钮使用原生语义元素，键盘焦点清晰，触控目标不小于 40px。

## 布局

- 顶部导航包含章节练习、模拟考试、错题集、收藏、搜索、题库管理。
- 主内容宽度受限并居中；手机端选项改为单列，表单与工具栏允许换行。
- 答题页由题型与进度、题号导航、题干/题图、答案区、翻页操作组成。
- 填空题输入框按空位排列；小屏幕上标签与输入框纵向排列。

## 状态

- `single`：主色标签。
- `multi`：警告色标签。
- `fill`：绿色标签。
- 正确答案为绿色，用户错误为红色，未作答显示文本而非仅用颜色表达。
