# 功能需求

## 1. 题库导入

- 支持 `.xlsx`，自动定位包含“章节、题型、题目、正确答案”的真实表头行。
- 支持单选和填空题；单选题选项列可从 A 扩展到 Z，多选题导入行会被跳过。
- 支持机械设计与机械原理两种现有工作簿列结构，并保留题目 ID、资料名称、考点、页码和题号等可选字段。
- 多空填空题默认按空位顺序判分；可通过“答案顺序=可交换”允许各空答案互换。
- 按题目 ID 优先更新，否则按“章节 + 题干”匹配；新题追加，坏行单独计数。
- 可读取“题图、图片、图片路径、题图文件”列，也可批量上传以题目 ID 命名的图片。

## 2. 练习与判分

- 按资料和章节分组，显示单选、填空数量。
- 选择题每轮打乱选项，答案仍按原始选项正确映射。
- 填空题按空位输入；判分忽略空格、常见标点和大小写，使用 `|`、`｜` 或 `/` 表示同一空的可接受答案。
- 所有题型统一交卷、统计正确率，并将错误题目加入错题集。
- 题图在练习、结果、错题、收藏和搜索页显示。

## 3. 模拟考试

- 可多选章节并分别设定单选、填空题数。
- 从所选范围随机抽题，数量不足时明确提示。
- 所有题型等权计分，总分 100 分。

## 4. 复习与检索

- 错题集记录错误次数，支持按章节筛选和重新练习。
- 收藏集支持查看、移除和重新练习。
- 搜索覆盖题干、章节、选项、答案和解析。

## 5. 数据管理与离线使用

- 完整 JSON 备份包含题库、错题、收藏、设置和本地题图。
- 可单独导出错题数据，清空操作必须二次确认。
- GitHub Pages 部署在仓库子路径时仍可注册 Service Worker，并缓存核心静态文件。
